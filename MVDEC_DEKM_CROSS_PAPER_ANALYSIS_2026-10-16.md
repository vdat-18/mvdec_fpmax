# DEKM 2021 and MvDEC 2025 cross-paper reproduction analysis

Date: 2026-10-16 (Asia/Bangkok)

## Objective

Reconstruct MvDEC 2025 as faithfully as the published evidence allows, with immediate focus on REUTERS View2 and fusion. The Google Drive dataset/checkpoint provenance in this workspace belongs to the user reproducing the work; it is not an artifact supplied by the MvDEC authors.

## What is directly supported

### DEKM 2021

- Text input: 2,000-dimensional TF-IDF.
- Encoder: `d-500-500-2000-10`; mirrored decoder; ReLU; Xavier initialization.
- Optimizer: Adam, learning rate 0.001, beta1 0.9, beta2 0.999.
- Stop rule: fewer than 0.1% assignment changes.
- Reporting: three runs, mean results.
- Table III DEKM_F: REUTERS 76.42/59.99, 20NEWS 41.20/43.76, RCV1 62.12/35.98.
- Algorithm/released behavior uses the last direction after ascending eigenvalue sorting and a frozen full-vector greedy target, despite prose calling that direction least informative.

### MvDEC 2025

- View1 is described as the same model used by DEKM.
- Eq. (3) gives the same `x_i` to the two encoders.
- Eq. (4) defines equal averaging: `(h1 + h2) / 2`.
- Eq. (5) reconstructs the same input through both decoders.
- Eq. (11) combines `L1 + L2 + L3 + L4`.
- Figure 2, for the 13-feature air-pollution example, visually gives View1 a 10D latent plus 13D reconstruction and View2 a terminal 23D output, then shows a 46D concatenation. The figure does not expose an unambiguous 10D View2 latent node.
- Section 3.3.4 explicitly names the smallest-eigenvalue direction.
- Table 2 evaluates View1 and View2 separately, repeats DEKM_F exactly for View1, and reports best performance.

## Internal contradictions and missing details

1. MvDEC prose discusses distinct attribute views, but Eq. (3) gives both encoders the same input.
2. Eq. (4) says average encoded representations, while Figure 2 shows concatenated terminal outputs.
3. The View2 latent extraction rule for 2,000-dimensional text inputs is not published.
4. The eigen-direction description conflicts with DEKM's algorithm/released behavior.
5. MvDEC does not publish seeds, run count, variance, checkpoint selection, or enough optimization detail to reconstruct its best-performance selection.
6. If the two views are trained independently, raw coordinate averaging is not geometrically invariant. If they are jointly trained, View1 should generally move, which conflicts with Table 2 reproducing the DEKM_F row exactly.

Therefore no single implementation can honestly be called uniquely paper-exact from the available text alone.

## Empirical evidence collected

### Frozen View1, fused View2 refinement

- View1: 0.7557/0.593243.
- View2: 0.4453/0.154589.
- Raw Eq. (4) fused: 0.7551/0.591741.
- View1 remained unchanged, but View2 was weak and fusion degraded the baseline.

### Frozen View1, independent View2 refinement

- View1: 0.7557/0.593243.
- View2: 0.5277/0.342850.
- Raw Eq. (4) fused: 0.7558/0.593393.
- Independent refinement improves View2 substantially but still misses MvDEC Table 2 View2 by 0.1224 ACC and about 0.17005 NMI.

### Scale and coordinate evidence

- Mean row norms: View1 0.833907, View2 0.069845; View2/View1 ratio 0.083757.
- Centered global RMS scale factor: 8.370935.
- Same-coordinate correlation mean: 0.017822.
- Strongest cross-coordinate absolute correlation mean: 0.466015.

This demonstrates both scale and axis mismatch. However, their practical effects differ.

### Controlled label-free fusion results

| Control | ACC | NMI |
|---|---:|---:|
| Raw Eq. (4) | 0.7558 | 0.593393 |
| Centered RMS only | 0.8232 | 0.608373 |
| Procrustes only | 0.7555 | 0.592834 |
| Centered RMS + Procrustes | 0.8182 | 0.599224 |
| Z-score | 0.8219 | 0.605181 |
| Paper fused reference | 0.7813 | 0.6141 |

Scale correction is the dominant useful intervention. Procrustes does not explain the paper result and reduces quality when added to scale matching. The reverse order is numerically identical up to `5.77e-13`, as expected for positive scalar scaling and orthogonal rotation.

### Label-aware scalar sweep

- Scale 5.0 is nearest to the paper pair: 0.7565/0.595461.
- Scale 8.25 maximizes both grid ACC and NMI: 0.8236/0.609145.
- No scalar recovers 0.7813/0.6141 simultaneously.

This sweep is diagnostic only and cannot be promoted to a protocol because labels selected the result.

## Best current interpretation

The evidence most strongly supports the following reconstruction narrative:

1. MvDEC's View1 result is inherited from DEKM_F rather than generated by an unconstrained joint optimization that materially changes View1.
2. View2 was likely trained with additional unpublished choices or selected from a different trajectory/checkpoint than the current reconstruction.
3. Some scale calibration, normalization, or equivalent parameterization is required for View2 to influence raw fusion. Without it, View1 dominates.
4. A global axis rotation is not the missing ingredient. Coordinate mismatch exists, but Procrustes correction is empirically unhelpful.
5. The paper's fused row cannot be obtained honestly by choosing a post-hoc scalar, because the target ACC/NMI pair does not lie on the observed scalar path.

## Next controlled experiment

Preregister one REUTERS seed-42 arm:

- Frozen, bitwise-verified DEKM_F View1.
- Independently trained View2 as the initialization.
- One fixed full-dataset centered-RMS scale factor, computed without labels.
- View2-only refinement through the calibrated Eq. (4) fused representation.
- No Procrustes, whitening, scalar sweep, label-based checkpoint selection, or seeds 43-44.
- Preserve all other architecture, optimizer, batching, target, eigen, and stopping decisions.

Gate before any multi-seed run:

- View1 weights remain bitwise unchanged.
- View2 loses no more than 0.01 ACC/NMI versus 0.5277/0.342850.
- Fused ACC and NMI both exceed frozen View1 0.7557/0.593243.
- Calibration remains label-free and fixed before evaluation.

Claim scope must remain `controlled_diagnostic_not_exact_paper_truth`. Even if the score approaches Table 2, numerical proximity alone is not evidence that this was the authors' unpublished protocol.

## Current conclusion

The reproduction is not blocked by data corruption or View1. It is blocked by under-specified View2 training and latent calibration. Independent View2 training plus centered RMS calibration is the most evidence-supported direction to test next; Procrustes alignment should not be carried forward.
